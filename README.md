# S.A.M.O

Telegram Mini App для управления каналами. Бот: @sam_0_bot.

## Архитектура

Статический интерфейс → Supabase Edge Functions → PostgreSQL.
Telegram initData проверяется на сервере; пользовательский Telegram ID никогда не принимается на доверии из тела запроса. Service role key и токен бота доступны только серверу. AI-ключи должны храниться зашифрованными отдельным серверным ключом.

## Состояние

Подготовлена первоначальная схема хранения. Приложение ещё не готово к запуску. Рабочие NR/TGG не изменены.

## Развёртывание

Одного SUPABASE_SERVICE_ROLE_KEY недостаточно для применения миграций и публикации Edge Functions: потребуется Supabase access token и доступ к базе (либо выполнение миграций владельцем через Dashboard). GitHub Secrets нельзя прочитать обратно; они доступны только запущенным workflows.

Бесплатные тарифы имеют квоты. AI оплачивается пользователем по тарифам выбранного провайдера. Расписание GitHub Actions не гарантирует точного времени публикации.
